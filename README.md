# ゼロから筋トレ

道具なし・1回20分・週3回。「今日なにをやるか」をぜんぶ決めてくれる、初心者のための自重トレーニング PWA。
完全無料・オフラインで動く・データは端末の中だけ。

## 起動

- Mac: `start.command` をダブルクリック → http://localhost:8804/ が開く
- スマホ: 同じ Wi-Fi で `http://<MacのIP>:8804/` を開き、「ホーム画面に追加」
- 公開するなら GitHub Pages / Netlify にフォルダごと置くだけ（ビルド不要）

Service Worker は file:// では動かないので、必ず http で配信する。

## 設計の芯

| しくみ | 理由 |
|---|---|
| **曜日を決めない**。「昨日やったか／今週何回やったか／何日あいたか」でルールエンジンが今日やるか休むかを決める | 初心者は「今日は何をすればいいか」で止まる。1日サボっても計画が崩壊しない |
| 昨日やったら今日は休み。3日連続はやらない。7日以上あいたら回数7割で再開 | 超回復（48〜72h）。やりすぎで筋肉痛→挫折、を防ぐ |
| 7つの動作パターン（押す／肩／引く／しゃがむ／片足／お尻／体幹）ごとに **ラダー（はしご）** | 壁腕立て→斜め→ひざつき→ふつう→足上げ… と自重のまま負荷を上げられる |
| 今日の目標回数 = 前回の最小回数 +1（時間なら +5秒）。「きつすぎ」なら据え置き、「楽すぎ」なら +2 | 漸進性過負荷を自動化。ユーザーが考えなくていい |
| 全セット上限回数に届いたら次の段へ。「きつすぎ＋下限未満」が2回続いたら一段もどる | 停滞・ケガの回避 |
| A「押す＋しゃがむ」→ B「引く＋片足」→ C「全身」の順で回す | 同じ部位を中1日以上あける |
| 道具（椅子／タオル＋ドア／テーブル／鉄棒／ダンベル／チューブ／リュック）の有無で種目を自動で飛ばし、同じ段に「道具あり版」があれば優先する（設定で切替） | 持っている道具を最大限使う。「引く」動作は道具なしだと限界があるため |
| 「メニューを決める」で Lv.○ にまとめて／パターンごとに種目を選べる。今日だけ／次回以降も固定 | 自動が合わない日・自分で組みたい人向け |
| 棒人間に鼻・目・つま先を描き、「うつぶせ／あおむけ」の説明を添える | どっちが前か分からない、という声への対応 |
| 開始前の**コンディションチェック**（睡眠・筋肉痛・気分を3タップ）。合計4以下なら自動で軽めモード | 疲れている日に無理をさせない。「サボり」ではなく「計画どおりの調整」にする |
| **4週サイクルの期分け**：導入→積み上げ→強化→回復週（セット−1・回数7割）。手動で回復週に切替も可 | ディロードで疲労を抜くと次の週に伸びる（停滞・ケガの予防） |
| **回復マップ**：部位ごとの最終実施日。あいている部位が多い型（A/B/C）を優先して選ぶ | 固定ローテーションだと、サボった週に偏りが出る |
| **停滞検知**：直近3回の最小セット回数が伸びていない種目を検出し、対策（テンポ音／一段やさしく／回復週）を提案 | 初心者は停滞の原因が回復側にあることに気づけない |
| **痛みの登録**：手首・ひじ・肩・腰・ひざ・足首・首 → その部位を使うパターンを期間中メニューから外す | 痛いのに同じ種目を続けてケガを長引かせるのを防ぐ |
| **チェックテスト**（4週に1回）：腕立て最大回数・スクワット最大回数・プランク最長秒 → 筋力スコアの推移グラフ | 見た目が変わる前に「数字で伸びている」ことを見せる |
| **週次レポート**（回数・セット・レベルアップ・部位バランス・先週比）と**実績バッジ**（18種） | 続けるための可視化。罰はなし |
| 回数種目の**テンポ音**（低音で下ろし2秒→高音で上げ1秒） | 「ゆっくり下ろす」が口で言われても身につかないため |
| **音声ガイド**（ブラウザ標準の読み上げ）：「次は○○、3セット」「休憩おわり」を声で | 画面を見ずに進められる。通信不要 |
| **鏡モード**：前カメラを左右反転で表示し、お手本の棒人間と自分の形を見くらべる（写真は保存しない） | 「自分がどう動いているか」は初心者には見えない |
| **じぶん人形**：レベルに応じて腕・脚・体幹が太くなる正面図＋称号（たまご→…→マスター） | 数字より体で成長を見せる |
| **スナック筋トレ**：休みの日に1種目1セット（1〜2分）。ローテーションには影響しない | exercise snacks。回復のじゃまをせず習慣を切らさない |
| **休憩クイズ**：セット間の休憩中に基礎知識の2〜3択クイズ（22問） | 休憩時間を学びに変える |
| **たんぱく質チェッカー**：体重×1.4g を目標に、食べたものをタップで加算 | k7 の知識を行動に落とす |
| **画像でシェア**：完了画面／週次レポートを PNG にして共有・保存（Web Share API） | 続ける動機づけ |
| **リマインダー .ics**：曜日と時刻を選んで繰り返し予定を書き出し、カレンダーに通知させる | Web アプリは自分から通知できない制約への回答 |
| **上下分割テンプレート U/L**：週4回設定 or 9週目以降で自動切替（設定で固定も可） | 慣れてきたら分割のほうが各部位を週2回回せる |
| **AIコーチ（任意）**：Gemini 無料枠で週のふりかえりコメントと種目の質問。キーは端末内のみ | 他機能はキーなしで全部動く |

## ファイル

- `index.html` — 本体（CSS / データ / ロジックを1ファイルに）
- `manifest.json`, `sw.js`, `icon-*.png` — PWA 用
- `icon-src.html` — アイコンの元（ブラウザで描いてスクショ→PNG）
- `start.command` — Mac 用起動スクリプト

## データ

`localStorage` のキー `zerokintore.v1` に JSON で保存。設定画面から書き出し／読み込みできる。

```
profile  : 名前・目標・週の回数・1回の時間
equip    : 持っている道具
settings : 休憩秒・音・バイブ・テーマ
levels   : パターンごとの現在レベル
last     : 種目ごとの前回記録（回数・きつさ・きつすぎ連続回数）
sessions : トレーニング履歴（種目・セットごとの回数・レベル変動・メモ）
body     : 体重
checkins : コンディション（睡眠/筋肉痛/気分、日ごと）
pain     : 痛みの登録（部位・開始日・日数）
tests    : チェックテスト（腕立て/スクワット/プランク/スコア）
badges   : 実績（id → 獲得日）
program  : 回復週の手動指定（deload / skipDeload：週の開始日）
protein  : 日付 → 食べたもの[{n,g}]（直近40日）
quiz     : 休憩クイズの回答（id → {c:正解か, d:日付}）
aiNotes  : 週の開始日 → AIふりかえり（キャッシュ）
settings.geminiKey : Gemini API キー（任意。端末内のみ）
```

## iOS の制約

- `navigator.vibrate` は iOS Safari では動かない（音だけ）
- 定時通知はサーバーが必要なので未実装
- 画面ロック防止（Wake Lock）は iOS 16.4 以降でホーム画面追加時に有効
